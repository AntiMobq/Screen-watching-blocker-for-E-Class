# Não comece a prova antes disso

O código precisa ser copiado, depois de copiar você ira ir na pagina do CPB PROVA e antes de clicar em iniciar,
vai abrir o inspecionar elemento usando botão direito ou CTRL+SHIFT+J, vai ir na aba Console, vai escrever allow pasting ou permitir colar para o Console deixar você colar o codigo, vai ter certeza que deu Enter né porfavor, depois disso vai colar o codigo e apertar enter, feito isso já pode iniciar a prova e ser livre do sistema democrático do colégio.
